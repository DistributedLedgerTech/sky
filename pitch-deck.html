[02] THE PROBLEM

Sending money is expensive. Securing it is about to get harder.

Four pressures, one opening: the corridor tax, the quantum clock, warehouse mining, and a last mile that card terminals never reached.

REMITTANCES01

The corridor tax

Mexico received $61.8B in 2025 (Banxico). The average transfer is $405, and a typical 3.5% fee costs the sender ~$14. xCoin's default relay-policy fee floor is 1 sat per virtual byte, about 1,480 sat for a typical payment, whatever the amount. That difference is the entire business: arithmetic, not a projection.

QUANTUM02

The signature time bomb

Nearly every existing blockchain rests on elliptic-curve signatures that quantum computers are expected to break. Retrofitting post-quantum cryptography onto a network already holding value is a hard fork most incumbents will struggle to execute.

MINING03

Warehouse capture

ASIC farms and industrial pools have pushed ordinary people out of proof-of-work. The security budget of most chains is now controlled by a handful of operators.

ACCEPTANCE04

The last mile

In cash economies, card terminals never arrived. Digital dollars still can't be spent where the money actually goes.

[03] THE ANSWER

xCoin: post-quantum at genesis, mining for people.

  • Post-quantum from block zero. Every spend is signed with ML-DSA-65 (FIPS 204), with a hash-based SLH-DSA fallback, and node connections use a hybrid post-quantum handshake (ML-KEM-768, XIP-4) from launch. No migration debt, no legacy curve to defend: the problem incumbents face is designed out at genesis.
  • MetalDAG proof-of-work. A memory-hard algorithm that leans on memory bandwidth, the one resource ordinary hardware already has plenty of. A Mac, a laptop, a browser tab: all can meaningfully take part.
  • Fixed, predictable money. Exactly 100,000,000 XID hard cap, 8 decimals, emitted under the Annual Tenth: a warm-up, 50 XID per block to block 220,000, then 10% less every 110,000 blocks, never below 1.5 XID. No discretionary issuance.
  • The full stack in-house. Node, wallet, native and browser miners, block explorer, and encrypted communications: one builder, one codebase discipline, no integration risk.

[04] TECHNOLOGY

MetalDAG: proof-of-work that resists capture.

Mining speed is bounded by memory bandwidth, the resource ordinary hardware already has. Every spend is post-quantum by rule, not by option.

MEMORY-HARD01

Bandwidth is the resource

Ethash-family design: memory-hard, so mining speed is bounded by memory bandwidth, not raw logic.

APPLE-SILICON-FAVORING02

Built for unified memory

Designed around the wide, fast memory of Apple Silicon. A Mac people already own is a genuinely good miner. The DAG is 4 GiB at launch and grows 128 MiB per 14-day epoch.

MAINNET03

Rehearsed, then launched

The node verifies MetalDAG with a light per-epoch cache; only mining needs the full DAG. Nodes, pool and miner were rehearsed on testnet A, now retired with its ledger archived at height 3,555. Mainnet genesis was mined 2026-09-26 00:00:00 UTC; mainnet is live.

POST-QUANTUM04

ML-DSA everywhere

PQ-only spend rules: only post-quantum outputs can be created, so there is no ECDSA or Schnorr path for any coin. The node accepts no private key over RPC; an offline wallet signs and the node broadcasts.

[05] MONETARY POLICY

Scarce. Fixed. Boring on purpose.

The schedule is consensus law. Anyone can read it in the code, and nobody can change it by decree.

Hard cap100MXID maximum supply, 8 decimals

Premine0Every XID is mined, none granted
  • The Annual Tenth. A warm-up of 6.25, 12.5 and 25 XID per block for 20,000 blocks each, then 50 XID per block to block 220,000 (~Dec 2028). After that the reward falls 10% every 110,000 blocks (~382 days), never below a 1.5 XID floor (reached ~2063 to ~2325). The last coin is mined ~2363.
  • No premine, no founder allocation. Genesis mints nothing; block 1 pays the first subsidy to whoever mines it. Every XID is mined, none are granted.
  • No discretionary issuance. The schedule is consensus law, not policy. Mainnet live since 2026-09-26 00:00:00 UTC: explorer ↗ · emission ↗

[07] THE MOAT

A hardware acceptance layer nobody else has.

Cryptographic tap-to-pay on NXP NTAG 424 DNA. My proprietary provisioning binds each chip to a product record with a unique encrypted per-chip key. Every tap is a signed, counter-protected message, not a scannable code.
